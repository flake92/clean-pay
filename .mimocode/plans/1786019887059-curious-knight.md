# Fix: Account merge blocked by Remnashop payment rollout gate

## Problem

When user tries to merge Telegram account with email account, the merge fails with error "Не удалось объединить аккаунты".

**Root cause**: Remnashop's database has a `payment_runtime_control` table with `legacy_rollout_gate_active = true`. This is a safety mechanism that blocks user merges during payment system migration. The dry-run merge succeeds (read-only), but the actual merge fails because the database trigger raises: `user merge disabled during payment rollout gate`.

## Changes Made (already committed)

1. **`src/backend/application/auth/manage-linked-account.ts`** — `failed()` now uses `ServiceError.prodMessage` for all error codes instead of generic fallback
2. **`src/backend/auth/telegram-account-merge.ts`** — Added FAILED/expired confirmation check; wrapped post-merge operations in try-catch
3. **Tests**: 13 new tests covering all fixes

## Remaining Fix: Disable Remnashop payment rollout gate

### Steps

1. **Check current gate state**:
   ```bash
   docker exec remnashop-db psql -U remnashop -d remnashop -c "SELECT * FROM payment_runtime_control;"
   ```

2. **Check for payment operations** (safety check):
   ```bash
   docker exec remnashop-db psql -U remnashop -d remnashop -c "SELECT count(*) FROM payment_operations;"
   ```

3. **Verify Alembic revision is 0050**:
   ```bash
   docker exec remnashop-db psql -U remnashop -d remnashop -c "SELECT version_num FROM alembic_version;"
   ```

4. **Verify all Remnashop containers use the same image**:
   ```bash
   docker inspect remnashop --format '{{.Image}}'
   docker inspect remnashop-taskiq-worker --format '{{.Image}}'
   docker inspect remnashop-taskiq-scheduler --format '{{.Image}}'
   ```

5. **Disable the gate** (if all checks pass):
   ```bash
   docker exec remnashop-db psql -U remnashop -d remnashop -c "UPDATE payment_runtime_control SET legacy_rollout_gate_active = false WHERE id = 1;"
   ```

6. **Verify the gate is disabled**:
   ```bash
   docker exec remnashop-db psql -U remnashop -d remnashop -c "SELECT legacy_rollout_gate_active FROM payment_runtime_control WHERE id = 1;"
   ```

7. **Test the merge flow** on the website
